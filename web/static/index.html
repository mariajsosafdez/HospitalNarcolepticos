How the simulation works

        
    
          
  1. The server launches one goroutine per patient. All of them run at the same time.
    2. 
          
  2. Each goroutine waits a random time, then its patient falls asleep (if awake) or wakes up (if asleep).
    3. 
          
  3. Every change goes through the hospital, which is protected by a sync.Mutex: only one goroutine at a time can assign a room, so two patients can never get the same bed.
    4. 
          
  4. This page reads a safe snapshot of the hospital twice per second, so you can watch the beds fill and empty live.
